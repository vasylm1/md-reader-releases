# Markdown Reader &amp; Editor — downloads

This repository exists **only to host release binaries and release notes** for
**Markdown Reader &amp; Editor**, a calm, focused Markdown viewer and editor. The
application source code is not here.

## Download

Get the latest build from the [**Releases**](https://github.com/vasylm1/md-reader-releases/releases)
page, or use the [download page](https://markdown-reader-editor.netlify.app/downloads.html).

| Platform | File |
| -------- | ---- |
| macOS (Apple Silicon) | `Markdown-Reader-<version>-arm64.dmg` |
| macOS (Intel) | `Markdown-Reader-<version>-x64.dmg` |
| Windows | `Markdown-Reader-<version>-<arch>-setup.exe` |
| Linux | `Markdown-Reader-<version>-*.AppImage` / `.deb` |

The macOS build is not signed or notarised by Apple. On first launch, right-click
the app and choose **Open** (or run
`xattr -dr com.apple.quarantine "/Applications/Markdown Reader.app"`), then confirm
once. After that the app updates itself from this repository.
