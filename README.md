# Verdano — downloads

This repository exists **only to host release binaries and release notes** for
**Verdano**, a calm, focused Markdown viewer and editor. The application source
code is not here.

## Download

Get the latest build from the [**Releases**](https://github.com/vasylm1/verdano-releases/releases)
page, or use the [download page](https://verdano.netlify.app/downloads.html).

| Platform | File |
| -------- | ---- |
| macOS (Apple Silicon) | `Verdano-<version>-arm64.dmg` |
| macOS (Intel) | `Verdano-<version>-x64.dmg` |
| Windows | `Verdano-<version>-<arch>-setup.exe` _(coming soon)_ |
| Linux | `Verdano-<version>-*.AppImage` / `.deb` _(coming soon)_ |

The macOS build is not signed or notarised by Apple. On first launch, right-click
the app and choose **Open** (or run
`xattr -dr com.apple.quarantine /Applications/Verdano.app`), then confirm once.
After that the app updates itself from this repository.
